⚠ Priority Zero · Must Complete First

P0 Dev Action: URL Migration

Before any content edits happen, the blog URL structure must be migrated. Skipping this breaks redirect maps and wastes link equity.

⚠ Do This First — Blocks All Content Work
Blog URL Migration: /post-slug/ → /blog/post-slug/
All existing posts live at /post-slug/. They need to move to /blog/post-slug/ via 301 redirects using Rank Math before any content is touched. This protects existing Google Search Console data and ensures all new posts inherit correct canonical structure.
  • Step 1 — Rank Math setup: Enable custom permalink prefix in Rank Math → set /blog/ as blog base slug
  • Step 2 — Bulk 301 redirects: Export full URL list → set up redirect rules in Rank Math Redirections module → verify in GSC
  • Step 3 — Update internal links: Run Screaming Frog after migration → fix any internal links pointing to old slugs
  • Step 4 — Verify GSC: Confirm old URLs show 301 → new URLs in Coverage report within 48hrs. Submit updated sitemap.
  • Step 5 — Clear cache: Purge all cache (Cloudflare + server) after redirect setup to prevent stale URL serving

RightNow Communications · Framework

SGE-R.A.I.S.E.™ Framework

Every content decision maps to one or more RAISE pillars. Applied to both audit actions and new post briefs.

R
Relevance
Content matches search intent exactly. Right topic, right depth, right format for the query.
A
Authority
E-E-A-T signals: expert authorship, citations, original research, institutional credibility.
I
Intent
Serves the user's real goal — not just the keyword. Informational, navigational, or transactional.
S
Structure
Headers, schema, FAQ markup, scannable format. AIO-ready for AI-generated answer boxes.
E
Engagement
Hook, dwell time signals, CTA, internal linking. Keeps users on site and drives next action.
