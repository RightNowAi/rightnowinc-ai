Overview

Purpose & Scope

This is the operational execution guide for improving Tend Life's organic search visibility and AI search citation footprint. It covers three sequential phases: technical SEO cleanup, SGE-RAISE content optimization of existing posts, and net-new content production.

All content work must comply with Tend's brand voice (Park Ranger archetype), missional posture (God is already active — we participate), and theology translation rules as defined in the Tend Life Internal Marketing Intelligence and Missio Dei Theological Framework documents.

Rule: Phase 1 must be fully complete before Phase 2 begins. Run a fresh Screaming Frog crawl after Phase 1 to confirm all technical issues resolved.

Phase 2

SGE-RAISE Content Optimization

Apply the SGE-RAISE framework to all existing /stories/ posts. Goal: turn published content into AI-citable source material. Complete Phase 1 entirely before starting Phase 2.

SGE-RAISE Checklist — Apply to Every Post
  • R Relevance: Confirm primary keyword and intent type (informational / exploratory). Map to one clear SGE query the post should own.
  • A Answer Block: Add TL;DR or definition block within first 100 words. 2–3 sentences, direct answer format.
  • A Answer Structure: Rewrite H2/H3 headers as question format where not already. One answer block per section (~40–80 words).
  • I Entity Enrichment: Ensure Tend, Plant With Purpose, and relevant named entities (people, places, Scripture references) appear consistently throughout.
  • S Schema: Add Article schema with author (Person), datePublished, dateModified, and description. Add FAQ schema if FAQ block present.
  • E E-E-A-T: Named author with bio confirmed. "Last Updated" date visible. Minimum 2 internal links to authoritative Tend pages. External references where relevant.
  • Voice Check: Run missional energy check — does content assume God is already active? Does it remove pressure? Are neighbors collaborators, not targets?

Brief Standard — All New Posts

Every brief must include the following before writing begins. No exceptions.

  • Primary keyword + SGE intent type
  • TL;DR answer (2–3 sentences written before the post is drafted)
  • H2 structure in question format
  • FAQ blocks planned (minimum 3 Q&As)
  • Schema type identified (Article + FAQ minimum)
  • Named entities to include (Tend, Plant With Purpose, Scripture, people)
  • Internal link targets (minimum 2)
  • Author assigned with bio
  • Missional energy check passed before publish
Target: 800–1,400 words. Flesch readability 65–80 (Normal to Fairly Easy). Translate theology — don't explain it. No academic density.

All Phases

Brand Guardrails

Every piece of content produced under this plan must pass these checks before publish.

✓Always
  • Frame Tend as an initiative of Plant With Purpose
  • Sound: inviting, plainspoken, wonder-filled, calm
  • Assume God is already present and active
  • Remove pressure from leaders
  • Frame neighbors as collaborators, not targets
  • Use approved CTAs: Learn more / Explore Tend / See how it works
  • Publish with a named author and bio
✕Never
  • Position Tend as a standalone nonprofit
  • Sound: preachy, urgent, activist, guilt-based, corporate
  • Use urgency language or pressure-based appeals
  • Use "Easy", "Launch", "Activate", "Save your neighborhood"
  • Reference theology without translating it to plain language
  • Publish without a named author
  • Use "The Tend Team" as author attribution
